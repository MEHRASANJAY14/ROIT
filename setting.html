Step 1

Control Panel में जाकर या Windows Search में Internet Options खोजकर open करें।

Step 2

Internet Properties में General → Tabs पर क्लिक करें और Tabbed Browsing Settings में दिए गए options को check करें।

Step 3

Privacy tab में जाकर Turn on Pop-up Blocker को Uncheck रखें।

Step 4

Advanced tab में जाकर आवश्यक settings को Check / Uncheck करें।

Step 5

Security → Trusted Sites → Sites पर क्लिक करें।

Step 6 – निम्न वेबसाइट add करें

https://mpgbbas.boirrb.net
https://mpgbdcfinx.boirrb.net:47000/SSO/ui/SSOLogin.jsp
https://mpgbdrfinx.boirrb.net:47000/SSO/ui/SSOLogin.jsp

Require server verification को Uncheck करें और सभी URLs Add करें।

Step 7

Trusted Sites में Custom Level पर जाकर नीचे दी गई settings को Enable करें:

  • Download signed ActiveX controls → Enable
  • Download unsigned ActiveX controls → Enable
  • Initialize and script ActiveX controls → Enable
  • Access data sources across domains → Enable
  • Display mixed content → Enable

Scroll Down → OK → Yes → Apply → OK
